---
title: "Best practices for API keys"
---

- Rotate API keys every 30 days for enhanced security.
- Avoid sharing your API key with third parties unless necessary, and sign formal agreements (DSA or DPA) to ensure data compliance.
- Use a proxy or wrapper when integrating third-party services, exposing only the needed data—not your raw API key.
- Restrict API usage with IP whitelisting.
- Monitor API key usage and immediately reset keys if suspicious activity is detected or partnerships end.
